# Diabetes Prediction System

This project uses Machine Learning to predict diabetes status based on health and lifestyle information.

## Dataset
CDC Diabetes Health Indicators (BRFSS 2015) from the UCI Machine Learning Repository.

## Models Used
- Logistic Regression
- Random Forest Classifier

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

## Project Goals
- Explore and visualize the dataset.
- Prepare data for machine learning.
- Train and evaluate classification models.
- Compare model performance.
- Test predictions using sample inputs.

**Note:** This is an educational project, not a medical diagnosis tool.
